# CS-210-reflection
Project: Airgead Banking Application 

Project Summary

For this project, I developed a C++ banking application that calculates how an investment grows over time using compound interest. The program allows users to enter their initial investment, monthly deposit, interest rate, and investment period. It then generates reports comparing the investment growth with and without monthly deposits. The purpose was to make financial calculations easier to understand and give users a way to see how their savings could grow.

What I Did Well

I believe one of my strengths in this project was organizing the program into manageable sections and making the financial reports easy to read. I focused on following the project requirements while keeping the calculations consistent. I also became more comfortable working with functions and understanding how different parts of a C++ program work together.

Areas for Improvement

One improvement I would make is adding more input validation to handle incorrect entries. I would also look for opportunities to simplify repeated calculations and improve the overall efficiency of the program. Another feature I would consider adding is the ability to save the financial reports so users can reference them later.

Challenges and Problem Solving

One of the more challenging parts of this project was getting the compound interest calculations to work correctly while generating two different reports. I worked through this by breaking the calculations into smaller steps and reviewing the results. I used course resources, examples, and testing to better understand where adjustments were needed. This helped me become more comfortable troubleshooting problems instead of immediately starting over.

Transferable Skills

This project helped strengthen my understanding of C++ functions, program structure, debugging, and working with calculations. These skills will be useful in future programming courses and projects. Since I already have experience with data analysis and SQL, I also found it interesting to see how programming can be used to process financial information and present useful results.

Maintainability, Readability, and Adaptability

I focused on making the program readable by using descriptive names, keeping the code organized, and separating different responsibilities into functions. This structure makes it easier to understand how the program works and where changes would need to be made. I also tried to keep the formatting consistent so another developer could follow the logic without unnecessary confusion. These practices will be important as I continue working on more complex programs.
